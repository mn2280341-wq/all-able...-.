## 🌟 نظرة عامة

**AllAble** هو تطبيق ويب ذكي شامل مصمم خصيصاً لتمكين ذوي الاحتياجات الخاصة. يجمع التطبيق بين السوشيال ميديا المترجمة تلقائياً، البحث الذكي، التواصل بدون كتابة، الذكاء الاصطناعي لفهم المشاعر، ونظام الأمان والطوارئ.

### ✨ الميزة الأساسية

التطبيق **يتكيف تلقائياً** مع نوع الإعاقة من أول استخدام، ويغير:
- 🎨 الواجهة والألوان
- 📝 طريقة عرض المحتوى
- 🎯 طريقة التفاعل

### 🎯 أنواع الإعاقات المدعومة

| النوع | الرمز | الميزات الخاصة |
|------|------|----------------|
| 👂 سمعية | `hearing` | لغة إشارة، نصوص، تنبيهات مرئية |
| 👁️ بصرية | `visual` | قراءة صوتية، تكبير، تباين عالي |
| ♿ حركية | `motor` | أزرار كبيرة، تحكم صوتي |
| 🧩 ذهنية/توحد | `cognitive` | تبسيط، رموز، ألوان هادئة |
| ✏️ صعوبات تعلم | `learning` | شرح مبسط، صور، خطوات واضحة |

## 🚀 الميزات الرئيسية

### 1️⃣ التكيف التلقائي الذكي
- اكتشاف نوع الإعاقة تلقائياً أو يدوياً
- تطبيق ثيم مخصص لكل نوع إعاقة
- تغيير حجم الخطوط والألوان والتباين

### 2️⃣ البحث الذكي بالذكاء الاصطناعي
- شرح أي كلمة أو مصطلح بطريقة مخصصة
- دعم البحث الصوتي
- عرض النتائج بأشكال متعددة (نص، صوت، صور، فيديو، لغة إشارة)

### 3️⃣ تحليل المشاعر بالذكاء الاصطناعي
- تحليل النصوص والمشاعر باستخدام Google Gemini
- اكتشاف الحزن، القلق، الخوف، الغضب
- اقتراحات ذكية للدعم النفسي

### 4️⃣ نظام الطوارئ الذكي
- زر طوارئ بضغطة واحدة
- إرسال الموقع الجغرافي تلقائياً
- إشعار جهات الاتصال المحفوظة
- معلومات نوع الإعاقة للمساعدة الأفضل

### 5️⃣ التحكم الصوتي الكامل
- أوامر صوتية للتنقل
- قراءة المحتوى صوتياً
- البحث بالصوت

### 6️⃣ قارئ الشاشة المدمج
- قراءة تلقائية لجميع العناصر
- دعم اختصارات لوحة المفاتيح
- تنقل سهل بدون ماوس

## 🛠️ التقنيات المستخدمة

### Frontend
- **HTML5** - البنية الأساسية
- **CSS3** - التصميم الحديث مع متغيرات CSS
- **JavaScript (ES6+)** - المنطق والتفاعل

### Web APIs
- **Web Speech API** - التعرف على الصوت والقراءة الصوتية
- **Geolocation API** - تحديد الموقع للطوارئ
- **LocalStorage** - التخزين المحلي

### خدمات خارجية
- **Google Gemini API** - الذكاء الاصطناعي وتحليل المشاعر
- **YouTube API** - دمج محتوى اليوتيوب
- **MediaPipe** - لغة الإشارة (Python)

## 🎮 كيفية الاستخدام

### 1. فتح التطبيق
```bash
# افتح index.html في المتصفح
# أو استخدم Live Server
```

### 2. الإعداد الأولي
1. عند فتح التطبيق لأول مرة، ستظهر شاشة اختيار نوع الإعاقة
2. اختر النوع المناسب لك
3. سيتم تطبيق الثيم المخصص تلقائياً

### 3. استخدام الميزات

#### البحث الذكي
```javascript
// اكتب أي كلمة في مربع البحث
// أو استخدم البحث الصوتي
// ستحصل على شرح مخصص حسب نوع إعاقتك
```

#### نظام الطوارئ
```javascript
// اضغط على زر الطوارئ الأحمر
// سيتم إرسال موقعك وبياناتك تلقائياً
// لجميع جهات الاتصال المحفوظة
```

#### التحكم الصوتي
```javascript
// فعّل التحكم الصوتي من الزر في الأعلى
// قل "بحث" للانتقال لصفحة البحث
// قل "طوارئ" لتفعيل نظام الطوارئ
// قل "اقرأ" لقراءة محتوى الصفحة
```

## ⚙️ الإعدادات

### مفاتيح API

قم بتعديل ملف `config.js` وأضف مفاتيحك:

```javascript
const CONFIG = {
  GEMINI_API_KEY: 'YOUR_GEMINI_API_KEY',
  YOUTUBE_API_KEY: 'YOUR_YOUTUBE_API_KEY',
  // ...
};
```

### تخصيص الثيمات

يمكنك تعديل ملف `css/themes.css` لتخصيص الألوان والخطوط:

```css
body.theme-visual {
  --primary-color: #f093fb;
  --font-size-base: 22px;
  /* ... */
}
```
